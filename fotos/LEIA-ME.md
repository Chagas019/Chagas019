# Fotos dos santos

Coloque aqui as fotos com exatamente estes nomes. Assim que um arquivo existir, o site mostra a foto no lugar do retrato estilizado (as iniciais).

| Arquivo | Santo |
|---|---|
| `carlo-acutis.jpg` | São Carlo Acutis |
| `papa-francisco.jpg` | Papa Francisco |
| `francisco-de-sales.jpg` | São Francisco de Sales |
| `maximiliano-kolbe.jpg` | São Maximiliano Kolbe |
| `santa-clara.jpg` | Santa Clara de Assis |
| `joao-paulo-ii.jpg` | São João Paulo II |
| `sao-gabriel.jpg` | São Gabriel Arcanjo |

Use preferencialmente fotos em retrato (vertical), com o rosto na parte de cima, com pelo menos 800 px de largura e com licença livre (por exemplo, do Wikimedia Commons).
