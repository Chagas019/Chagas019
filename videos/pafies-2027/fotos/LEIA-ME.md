# Fotos das edições anteriores

Coloque aqui fotos reais da Gincana Solidária PAFIES com estes nomes:

| Arquivo | Aparece como |
|---|---|
| `foto-01.jpg` | 1ª edição |
| `foto-02.jpg` | 2ª edição |
| `foto-03.jpg` | 3ª edição |
| `foto-04.jpg` | 4ª edição |
| `foto-05.jpg` | 5ª edição |
| `foto-06.jpg` | 6ª edição |
| `foto-07.jpg` | 7ª edição |
| `foto-08.jpg` | 8ª edição |
| `foto-09.jpg` | 9ª edição |

Enquanto um arquivo não existir, o cartão mostra uma textura no lugar. As duas primeiras aparecem já na abertura, em tom envelhecido, como "fotografias antigas".

Use fotos na horizontal, com pelo menos 1200 px de largura. Nomes e legendas podem ser trocados em `config.js` (lista `fotos`).
