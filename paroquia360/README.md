# Paróquia360

**Toda a vida paroquial em um só lugar.** Plataforma SaaS multi-paróquia de gestão pastoral.

- `prototipo/` — protótipo navegável (dados de exemplo): `index.html` (painel), `escalas.html`, `agenda.html`. Base comum em `p360.css` e `p360.js`.
- `app/` — o app Next.js (ver `app/README.md`).
- `supabase/` — migração do banco (schema + RLS), `seed.sql` fictício e testes de acesso: `bash supabase/tests/run.sh`.
- `docs/` — documentação central. Comece por `docs/PROJECT_OVERVIEW.md` e `docs/ROADMAP.md`.
